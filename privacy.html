PAPQuack Personal Backups: Privacy Policy

This tool is for the operator's personal use.

Google Drive access

The tool requests the drive.file permission to create, read, update and delete files authorized for this application, including its backup repository. It does not request access to all existing Google Drive files.

Data use and storage

Selected local files are encrypted by restic before upload to Google Drive. The tool uses backup contents and metadata only to perform backups, integrity checks, retention management and restoration.

OAuth credentials are stored locally to allow authorized access. Backup data is not sold, used for advertising, or sent to an operator-run collection service. Google processes stored data under its own service terms and privacy policy.

Retention and control

Backups remain until the owner deletes them or applies a retention policy. Access can be revoked in the Google Account's third-party connections settings. Revoking access does not automatically delete existing backups.

This website

This informational site is hosted by GitHub Pages and contains no application login, backup uploads, or added analytics. GitHub may process standard hosting request information under its privacy policy.
